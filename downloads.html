Quick start
Install in 4 steps.
1
Download the ISO(Do NOT use the "Install to system" file on the desktop it is for dependency purposes and will soon be removed use the System Installer file on the desktop for installation)
Grab the ISO for your edition. Verify the SHA256 checksum before proceeding(when provided).
2
Flash to USB
Use dd, Balena Etcher, or Ventoy (recommended). Minimum 8 GB USB.
dd if=isofilename.iso of=/dev/sdX bs=4M status=progress
3
Boot & Install
Boot from USB (F12 / F2 on most systems). Follow the guided installer — ~8 minutes on NVMe.
4
You're in.
Log in, update with sudo dnf distro-sync, and you're running.
