Quick start
Install in 4 steps.
1
Download the ISO
Grab the ISO. Verify the SHA256 checksum before proceeding.
2
Flash to USB
Use dd, Balena Etcher, or Ventoy. Minimum 8GB USB drive and ventoy recommended. Command: dd if=Neo-44.iso of=/dev/sdX bs=4M status=progress
3
Boot & Install
Boot from USB (F12 / F2 on most systems). Follow the guided installer — takes about 8 minutes on NVMe.
4
You're in.
Log in, update with sudo dnf distro-sync, and you're running.
