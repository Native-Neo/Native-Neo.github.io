Quick start
Build in 4 steps.
1
Clone the repo
Get the source from GitHub. git clone https://github.com/Native-Neo/Neo.git cd Neo
2
Install build dependencies
Neo Linux is built with KIWI-NG. Install it on a Fedora host. sudo dnf install python3-kiwi kiwi-tools
3
Run the build
Follow the build instructions in the repo's README — this produces a bootable ISO from the current source tree.
4
Flash & install
Flash your built ISO with dd, Balena Etcher, or Ventoy, then boot from USB and follow the guided installer.
